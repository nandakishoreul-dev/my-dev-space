# CampusPulse 🚀

CampusPulse is a beginner-friendly campus issue reporting API built using Python and FastAPI.

The project allows students to report problems around their campus, such as broken fans, classroom equipment issues, or other infrastructure problems.

## Features

- Create a campus issue
- View all reported issues
- Categorize issues
- Set issue priority
- Add issue location
- Interactive API documentation using Swagger

## Tech Stack

- Python
- FastAPI
- Pydantic
- Uvicorn
